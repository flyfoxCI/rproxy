# rproxy v0.2.1

在 v0.2.0 的代理协议、认证和四种选路策略基础上，补齐 Linux / macOS 的 ARM64 与 x86_64 二进制发布。

## 五个平台发布包

| 系统 | 架构 | 文件 |
|---|---|---|
| Linux | x86_64 / AMD64 | `rproxy-v0.2.1-x86_64-unknown-linux-musl.tar.gz` |
| Linux | ARM64 / AArch64 | `rproxy-v0.2.1-aarch64-unknown-linux-musl.tar.gz` |
| macOS | Intel x86_64 | `rproxy-v0.2.1-x86_64-apple-darwin.tar.gz` |
| macOS | Apple Silicon ARM64 | `rproxy-v0.2.1-aarch64-apple-darwin.tar.gz` |
| Windows | x86_64 | `rproxy-v0.2.1-x86_64-pc-windows-msvc.zip` |

- 每个目标在对应架构的原生 runner 上构建，并执行 `--version` 和 `check-config` 检查。
- Linux 静态链接 musl；macOS deployment target 为 11.0，包目前未做 Apple Developer 签名/公证。
- 每个压缩包包含程序、示例配置、README 和 Python 维护脚本。
- `SHA256SUMS` 包含全部五个压缩包的 SHA-256。发布前严格检查目标集合，缺少任一架构、混入旧版本或出现额外归档时拒绝公开 Release。

## 兼容性

代理功能与 v0.2.0 保持一致；现有配置和 Redis 数据无需迁移。Python 维护脚本仍要求 Python 3.10+，构建/打包工具使用 Python 3.11+。

v0.2.0 已有的标签和发布包保持不变，不移动或覆盖旧版本。
